## 작업 위치

| 항목 | 값 |
| --- | --- |
| 작업 위치 | `workstream/003-verify-and-report` |
| 기준 브랜치 | `main` |
| 반영 대상 브랜치 | `main` |
| 원격 작업 흔적 | 남기지 않음 — push하지 않습니다 |

계획 커밋도 작업 브랜치에 둡니다. 사용자가 `main`을 건드리지 않는 조건으로
진행을 요청했기 때문입니다. `workstreams.md`의 기본 절차와 다른 점이며, 그
이유는 `decisions.md`에 있습니다.

**이번 대작업은 사용자 지시로 반영과 아카이브를 하지 않습니다.** 결과를 보고
사용자가 정합니다.

## 현재 단계

`plan.md`의 2단계 진행 중입니다. 맥락 없는 별도 세션이 픽스처에 `0.2`를
적용하고 있습니다.

## 직전 완료

임시 기존 프로젝트 픽스처를 만들었습니다. 기존 `AGENTS.md`(제약 2개 + 커밋
규칙 + 검증 명령), `TODO.md`(진행 중·완료·언젠가), 코드 한 파일, 커밋 하나가
들어 있고 각 항목에 추적용 표식이 붙어 있습니다. 커밋 규칙은 영어로 두어
골격 기본값과 어긋나게 했습니다.

## 다음 행동

적용 결과가 오면 표식 보존 여부와 검사기 통과를 확인하고, 3단계에서
워크스트림을 열어 일부만 진행합니다.

  대신할 수 없고, 맥락 없이 시작하는 별도 에이전트로 근사합니다.
