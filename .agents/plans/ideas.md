# 아이디어

> 아직 착수를 약속하지 않은 기능과 선택적 개선 후보를 관리합니다.
> 해결해야 하는 현재 문제나 진행 중인 작업은 이 파일에 두지 않습니다.

- **템플릿 영어판.** 지금 골격 문서는 한국어뿐입니다. `README.en.md`는 있지만
  정작 복사되는 내용이 한국어라 영어 사용자는 직접 번역해야 합니다. 실제로 쓰는
  사람이 생기면 착수합니다.
- **npm 레지스트리 등록.** 지금은 `npx github:Jammanb0/cairn`으로만 받습니다.
  등록하면 `npx cairn-agents check .`로 짧아지고, Git 없이도 설치되며 버전
  고정이 `@0.1.2`라는 표준 형태가 됩니다.
  제약이 넷입니다. `cairn`은 이미 다른 패키지가 쓰고 있어 `cairn-agents`를
  써야 합니다(2026-09-07 확인 시 비어 있음). 이름은 한 번 정하면 되돌리기
  어렵습니다. 릴리즈마다 GitHub Release와 npm 두 곳에 내야 해서 어긋날 수
  있습니다. 자동 배포하려면 npm 토큰이 필요한데, 지금 이 저장소는 시크릿을 쓰는
  곳이 없습니다 — 넣는다면 `AGENTS.md`의 「보안과 개인정보」대로 GitHub
  Secrets에 두고 파일로 두지 않습니다. README 설치 안내도 두 벌이 됩니다.
- **검사 항목 확대.** 지금 `cairn check`는 연결과 워크스트림 상태를 봅니다.
  아카이브로 옮긴 워크스트림이 `history.md`에 적혀 있는지처럼 더 볼 것이
  있는지 살펴봅니다.

새 후보가 생기면 기대 효과와 제약을 짧게 적습니다. 구현을 결정하면 이 파일에서
지웁니다. 그다음은 `workflow.md`의 「대작업 관리 흐름」을 따릅니다 — 대작업이면
`workstreams/<번호>-<이름>/`을 만들고, 아니면 그냥 합니다.
