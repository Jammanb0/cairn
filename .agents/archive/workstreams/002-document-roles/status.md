## 최근 완료한 것

- 이 저장소의 운영 문서와 배포 골격을 새 구조로 옮겼습니다.
- 검사기가 새 규격의 필수 문서를 보고, 이전 구조를 만나면 무엇이 어디로
  나뉘었는지 알려 줍니다. 시험은 34개가 통과합니다.
- 세팅 워크스트림 골격을 넷으로 나누고 `APPLY.md`, README 두 벌, 시험 기록을
  맞췄습니다. 버전은 `0.2.0`입니다.

## 다음 행동

## 막힌 점과 열린 질문

- `main` 반영은 사용자 확인을 받고 실행합니다. 브랜치를 판 이유가 반영 전에
  내용을 보기 위해서였습니다.

  않았습니다. `docs/trials/README.md`의 「앞으로 검증할 것」에 남겼습니다.
